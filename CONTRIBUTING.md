# Contributing

The general guide is the byterefs
[contributing guide](https://github.com/byterefs/.github/blob/main/CONTRIBUTING.md).
For this repository in particular:

1. A change starts as an issue. Use the "Specification proposal" template
   for anything that changes meaning.
2. Once discussed, it becomes a decision record in `decisions/`, proposed in
   a pull request (see [decisions/README.md](decisions/README.md)).
3. The specification text in `spec/` changes when the record is accepted,
   and the record is cited in the specification's changes section.
4. Editorial fixes (typos, links, wording that does not change meaning) can
   go straight to a pull request.
